ALPACA configuration reference

Find what an option does, what it accepts, and when to change it—without losing your place in the pipeline.

219 documented options 19 sections
The configuration is one JSON object with ten blocks — run, data, mass, light, stages, psf, likelihood, sampling, plotting, blinding — organised around the pipeline itself: the physical model (mass, light), the MAP stages in execution order (stages.gd → stages.cf_warmstart → stages.cf_joint, with the lens-light refit living with the light it refits under light.lens.refit), and the inference (likelihood, sampling). What you write is exactly what gets saved back into the run directory. Configs from older ALPACA versions are detected and upgraded automatically on input. The teal default chip shows the value used by the bundled HE0435-1223 example run in config.json; its six omitted advanced settings show their resolved pipeline values.
01

run

What runs, where output goes, reproducibility.

run.output_dirstr
"run/"

Root directory for all pipeline outputs (input snapshots, PSF stage, multistart, sampling, plots, timing). The literal token {date} is replaced with a YYYY-MM-DD_HH-MM timestamp when the config is built, so every run lands in its own sub-folder. A trailing slash is added if missing; an empty string, null, or an omitted key falls back to pipeline_output (the {date} expansion only happens in the run scripts, so the dataclass deliberately does not default to the {date} path).

Resume logic (staged joint-PSF stages, resume_from_previous) keys off directories inside output_dir — reuse the same directory (no {date} token) if you want reruns to skip completed stages.
run.random_seedint
42

Master PRNG seed, propagated to every stochastic component: multi-start initial positions, Adam/L-BFGS randomness, sampler chains, posterior subsampling. Fixing it makes runs bit-reproducible on the same hardware/software stack; change it to probe run-to-run scatter of the multistart.

run.verbosebool
true

Master verbosity toggle applied to every pipeline stage — progress prints, per-start GD summaries, sampler diagnostics. Does not affect what is written to disk, only console output.

run.multistartbool
true

Run the multi-start gradient-descent MAP stage (03_multistart/). Nearly always true — the MAP point seeds the sampler, defines the signal-derived arc mask, and (in joint PSF mode) carries the PSF fit. Set false only to start sampling directly from prior means or from a previous run's best fit.

run.samplingbool
true

Run posterior sampling (NUTS / Nautilus / NIFTy) after gradient descent. Disable to stop after the MAP stage — useful for quick model checks, arc-mask tuning, or PSF-stage debugging where the posterior is not needed yet.

run.resume_from_previousbool
false

Only consulted when run.multistart=false: if true, load the best-fit parameters from a previous run's 03_multistart/ directory and use them as the sampling start point; if false, start from prior means.

The loaded best fit must come from a compatible model — the staged flow fingerprints the likelihood config and warns (and invalidates later stages) when the objective changed, e.g. a time-delay flip.
run.resume_multistart_pathstr | null
null

Explicit path to a previous run's 03_multistart/ directory. When null, the path is derived from output_dir. Only used when resume_from_previous=true.

02

data

Imaging geometry, masks, point-source detection.

data.pix_scalefloat (arcsec/pixel)
0.031228698402951588

Detector pixel scale of the science image. Read it from your FITS header (CD1_1/CD2_2 or D001SCAL). Common values: drizzled HST/WFC3 = 0.04, JWST/NIRCam short-wave = 0.031. Everything angular in the pipeline (masks, priors on offsets, PS separation) is expressed in arcsec and converted with this scale, so an incorrect value silently corrupts the whole geometry.

data.source_oversampleint
3

Source-plane supersampling factor of the forward model: the internal source grid is this many times finer than the data pixels and is downsampled on output. Memory scales roughly quadratically. 3 is usually plenty; 5 adds marginal accuracy at ~2.8× the memory.

data.likelihood_mask_pathstr | null
"data/mask_likelihood.fits"

Optional boolean mask for the main lens-model likelihood — companions, diffraction spikes, cosmic-ray residuals, and detector defects. Only True pixels contribute; null disables the mask.

The .npy or .fits array may match either the modelling cutout or the original full science frame. When data.cutout_size is active and a full-frame mask is supplied, ALPACA center-crops it with exactly the same offset as the image and noise map. A cutout-sized mask is used directly.

This mask belongs to the main fit and is distinct from the full-frame light.lens.refit.mask_path. The same full-frame file may be used for both paths only when its pixel selection is intentionally suitable for both fits.

A line-of-sight perturber's LIGHT is modelled only when its catalog entry has a lens_light block — mask every other perturber galaxy here or its flux is fitted by the lens light / source and biases the fit.
related data.cutout_size light.lens.refit.mask_path
data.ps_min_sepfloat (arcsec) | null
null

Minimum separation between detected point-source images. Local maxima closer than this get merged into one candidate. Two native pixels is a safe default; raise it if noise spikes near an image split one quasar image into two detections.

data.ps_lens_mask_radiusfloat (arcsec)
0.35

Radius of the central mask around the lens-galaxy centre that is excluded from point-source detection, so the bright lens core is not picked up as a fifth image. Shrink it when a genuine quasar image sits close to the lens galaxy (small-separation quads, fold configurations).

data.ps_min_peak_fracfloat
0.15

Minimum fraction of the brightest unmasked peak for a local maximum to count as a point-source candidate. Lower it (e.g. to 0.05) for high-magnification-ratio quads where the faintest image is far dimmer than the brightest; raising it suppresses spurious detections from bright arc knots.

data.lens_center_search_radiusfloat (arcsec)
0.35

Radius within which the lens-galaxy centre is refined from the seed position. Shrink it for asymmetric systems where a bright point-source image lies within the search radius — otherwise the refinement locks onto the quasar image instead of the galaxy.

data.cutout_sizeint | null
219

If set (and smaller than the loaded image), the pipeline center-crops the loaded image and noise map to this many pixels per side for every normal modelling stage and sampling. A full-frame data.likelihood_mask_path is center-cropped with the same offset; an already cutout-sized likelihood mask is accepted unchanged.

The full loaded frame is retained for the lens-light refit, which fits the parametric light on the larger frame for better outer-profile and sky constraints. Its cutout-invariant parameters transfer back to the cropped model unchanged, and its separate mask must match the full frame.

related data.likelihood_mask_path light.lens.refit.mask_path
03

mass.main

Main-deflector mass: radial profile (EPL+Shear or BPL+Shear) plus optional angular multipoles.

mass.main.profilestr
"EPL+Shear" allowed"EPL+Shear", "BPL+Shear"

Radial mass profile of the main deflector.

  • "EPL+Shear" — elliptical power law + external shear, one slope lens_gamma. The historical model (legacy alias "epl").
  • "BPL+Shear" — elliptical broken power law + external shear (legacy alias "bpl"): slope gamma_in inside a break radius, gamma_out outside. Samples lens_gamma_in, lens_gamma_out, lens_r_break_frac and removes lens_gamma. Reduces to the EPL exactly at gamma_in = gamma_out (verified to ~1e-13), and θE keeps its EPL meaning (mean convergence 1 inside θE) so the two models are directly comparable.

The BPL has no closed-form deflection — it is evaluated by desingularised Gauss-Legendre quadrature (Keeton 2001), costing ~×1.8 per gradient.

The profile string selects the RADIAL model only — angular structure is added independently via mass.main.multipoles.orders (combinable with either profile), and the external shear is always part of the model.

related mass.main.multipoles.orders
mass.main.multipoles.orderslist[int]
[]

Angular multipole orders added to the main deflector, e.g. [3, 4]. Each order m adds the convergence κ_m = a_m·cos[m(φ−φ_m)]/(2r) and TWO sampled sites, the Cartesian pair lens_a{m}_cos/lens_a{m}_sin (single-valued and smooth through zero — the polar (a_m, φ_m) pair is 2m-fold multimodal and singular exactly at the a_m=0 null-test point). All amplitudes zero = the EPL, bit-for-bit.

m=4 is boxy/discy — the mode with real photometric backing (a₄/a ~ 1–2% in ellipticals). m=3 is the triangular mode. m=1 is supported (it needs a special r·ln r potential — the scale-free form divides by zero) but see the warning.

related mass.main.profile
mass.main.multipoles.sigmafloat | dict
null

Width (arcsec) of the zero-mean Normal prior on each Cartesian amplitude; a dict maps order → σ with sigma_default as fallback. The example uses null, so every configured order delegates to sigma_default = 0.02. Scale intuition: a_m/θ_E is the usual dimensionless strength; real ellipticals sit at 0.01–0.02, so σ=0.02" (~2% of a typical θ_E) is weakly informative and lets the data push to ~5%.

mass.main.multipoles.sigma_defaultfloat
0.02

Fallback prior width used for any multipole order not listed when multipoles.sigma is a per-order dict (or when it is null).

mass.main.multipoles.r_ref_m1float
1.0

Reference radius (arcsec) in the m=1 potential ψ₁ = ½·r·ln(r/r_ref)·C(φ). Changing it only adds a CONSTANT deflection — exactly degenerate with a source-plane shift, leaving the convergence untouched — so it is held fixed (~θ_E) rather than sampled. Ignored without m=1.

mass.main.bpl.gamma_indict
{"loc": 2.0, "scale": 0.3, "low": 1.3, "high": 2.7}

TruncatedNormal prior on the INNER slope (same shape as the EPL's gamma_prior; bpl.gamma_out is the outer twin). Deliberately WIDER than the EPL default (scale 0.3 vs 0.15): a broken profile splits the single well-constrained lensing slope between two parameters, and a tight prior would just re-impose the EPL answer.

related mass.main.bpl.gamma_out
mass.main.bpl.gamma_outdict
{"loc": 2.0, "scale": 0.3, "low": 1.3, "high": 2.7}

TruncatedNormal prior on the OUTER slope — the twin of mass.main.bpl.gamma_in (see that entry for why the priors are deliberately wide). Sub-keys: loc/scale are the Normal centre and width, low/high the truncation bounds.

related mass.main.bpl.gamma_in
mass.main.bpl.r_break_fraclist[float]
[0.5, 2.0]

Uniform prior bounds on the break radius in units of θE (site lens_r_break_frac). Tying the break to θ_E keeps it inside the annulus the arcs actually constrain for every sample, instead of letting the chain wander into a regime where the second slope is unconstrained.

mass.main.bpl.n_quadint
24

Gauss-Legendre nodes PER PANEL (two panels, split analytically at the break) for the BPL deflection; n_quad_potential (default 28) is the potential's counterpart. 24 reproduces the analytic EPL to ~1e-13 at γ=2 (where the endpoint substitution makes the quadrature exact) and stays below 1e-6 relative down to q~0.55. Lower only if profiling says so.

mass.main.theta_E_priordict | null
null

Optional informative prior on the main-lens Einstein radius. null keeps the wide Uniform(0.5 r_min, 1.5 r_max) driven by the detected image positions. {"center": <arcsec>, "sigma": <arcsec>} samples theta_E from a TruncatedNormal clipped to the same physical bounds — useful to test whether pinning theta_E to an external measurement changes the fit or the outer-arc residual.

mass.perturbers

Line-of-sight perturbers from a catalog (SIS/SIE/EPL/EPL+Shear mass, optional lens light); may switch the model to multi-plane lensing.

mass.perturbers.pathstr | null
"data/perturbers.json"

Perturber catalog JSON (a target block + perturbers list, as written by the perturber-finder tool). null disables perturbers entirely — the model is then byte-identical to the plain single-plane pipeline. When set, each selected perturber contributes its catalog-declared mass profile; perturbers outside the main-plane redshift window get their own planes and switch the forward model to multi-plane lensing (Herculens MPLensImage).

Per-dataset path — prefer setting it via PERTURBERS_PATH in run_alpaca.py.

A perturber's light is modelled only when its catalog entry carries a lens_light block — mask every other perturber galaxy with data.likelihood_mask_path, or its flux biases the fit.
mass.perturbers.modestr
"auto" allowed"auto", "single_plane"

"auto" gives honest plane assignment: perturbers within z_tolerance of the lens redshift join the main plane as ordinary profiles; the rest get their own fore-/background planes, switching to multi-plane ray tracing with distance ratios fixed at the fiducial cosmology and arrival times rescaled by the sampled D_dt. "single_plane" forces all perturbers into the main lens plane — the classic approximation that keeps the cheaper single-plane forward model.

mass.perturbers.z_tolerancefloat
0.01

Redshift window around the lens: perturbers with |z − z_lens| ≤ z_tolerance are placed in the main lens plane. Must be ≥ 0 (validated). Widening it trades multi-plane fidelity for a simpler, faster model.

mass.perturbers.min_flexion_shift_arcsecfloat | null
null

Drop catalog perturbers whose flexion shift is below this threshold. The flexion shift is the standard importance ranking for line-of-sight structure — a threshold around 10⁻⁴ arcsec keeps only perturbers that measurably affect the model.

mass.perturbers.include_idslist[int] | null
null

Explicit whitelist of catalog ids. When set, only these perturbers are modelled (still subject to the flexion cut). null = no whitelist.

mass.perturbers.exclude_idslist[int] | null
null

Explicit blacklist of catalog ids to drop regardless of other filters. null = no blacklist.

mass.perturbers.priors.theta_E_max_factorfloat
3.0

Each perturber's Einstein radius gets a Uniform(0, factor × θ_E,catalog) prior. The factor absorbs catalog mass uncertainties; 3× is generous without letting a perturber grow into a second main deflector.

mass.perturbers.priors.position_sigma_arcsecfloat (arcsec)
0.3

Normal prior width on each perturber centre around its catalog position (converted into the model frame). Wide enough to absorb astrometric frame offsets; the overlay plot in 01_input/ shows the anchors so you can verify the conversion.

mass.perturbers.priors.fix_positionsbool
false

Freeze perturber centres at the catalog positions — no position latents; only θ_E stays free. Cuts two latents per perturber; use when the catalog astrometry is trustworthy and the perturbers are weak.

mass.perturbers.cosmology.H0_fidfloat (km/s/Mpc)
70.0

Fiducial H₀ for the multi-plane distance-ratio (η) matrix and the fiducial time-delay distance used to rescale multi-plane arrival times onto the sampled D_dt. Distance ratios are exactly H₀-independent, so this choice does not bias the H₀ inference — it is the standard treatment.

mass.perturbers.cosmology.Om0float
0.3

Fiducial matter density for the multi-plane distance ratios. The dependence of the ratios on Ω_m is weak; 0.3 is the conventional choice.

light

Lens light and its whole lifecycle (including the staged refit), sky background, point sources.

light.lens.initialstr | null
"double-sersic" allowed"sersic", "double-sersic", "triple-sersic", "MGE", "MGE+double-sersic", "MGE+triple-sersic"

Preferred single-string interface for the lens-light model (2026-07). It sets the four legacy booleans (use_double_sersic_lens, use_triple_sersic_lens, use_mge_lens_light, mge_as_correction) consistently:

  • "sersic" — single Sersic profile.
  • "double-sersic" — bulge + envelope.
  • "triple-sersic" — plus a third component for core corrections.
  • "MGE" — a Multi-Gaussian Expansion replaces the Sersics entirely.
  • "MGE+double-sersic" / "MGE+triple-sersic" — Sersics carry bulge+envelope, a small Gaussian stack absorbs residual core mottling.

When null, the string is derived from the legacy booleans, which remain supported for old configs and are kept in sync at validation. The number of MGE components stays a separate knob (mge_n_components).

related light.lens.refit.profile
light.lens.refit.enabledbool
true

Master switch for the staged lens-light refit. When enabled, after the cf_warmstart stage the pipeline subtracts the current (source + point-source) model from the data and fits the lens light ALONE on the residual — no mass model involved — then carries that light into cf_joint (fixed or free per stages.cf_joint.lens_light). The sampling stage frees the light again, warm-started from the refit values.

related stages.cf_joint.lens_light
light.lens.refit.profilestr
"triple-sersic" allowed"same", "sersic", "double-sersic", "triple-sersic", "MGE", "MGE+double-sersic", "MGE+triple-sersic"

Complexity of the refit light model. "same" reuses light.lens.initial; any other lens-light option ("sersic", "double-sersic", "triple-sersic", "MGE", "MGE+double-sersic", "MGE+triple-sersic") may be MORE complex than the first try. From the refit onward this becomes the lens-light parametrization of the whole pipeline. The shipped example uses "triple-sersic". (This key was previously spelled lens_light; the old spelling is still accepted on input.)

related light.lens.initial
light.lens.refit.mge_n_componentsint | null
null

MGE components for the refit light model; null inherits light.lens.mge.n_components.

related light.lens.mge.n_components
light.lens.refit.adam_stepsint
3000

Optimization budget of the light-only fit.

light.lens.refit.simple_sourcestr
"stage1" allowed"cf", "stage1"

Which source model is subtracted (with the point sources) to build the refit target. "cf": the cf_warmstart correlated-field source — but a noisy CF source leaks flux to the cutout edges and contaminates the target. "stage1": the SMOOTH stage-1 shapelets source, so the target is clean; the CF source then fits the residual arc detail in cf_joint with the light frozen. Decouples the light refit from CF noise.

light.lens.refit.ps_treatmentstr
"mask" allowed"downweight", "mask", "sigma_clip"

How the light-only fit protects itself from point-source residuals — the three modes are mutually exclusive and this is the single knob:

  • "downweight" — inflate sigma 100× inside ps_downweight_radius of each point source.
  • "mask" — zero-weight that same region entirely.
  • "sigma_clip" — no positional region at all: fit over the whole frame, then reject pixels by RESIDUAL (|target − light|/sigma > ps_sigma_clip) and refit, iterating until the clipped set is stable. Rejects PS cores, cosmic rays and neighbour-galaxy wings wherever they actually land, and keeps every good pixel a positional mask would have thrown away.

Whichever mode is used, it is internal to the refit only — the main pipeline's likelihood mask is untouched.

light.lens.refit.ps_downweight_radiusfloat (arcsec)
0.5

Radius of the region around each point source that is downweighted or masked. Used by "downweight"/"mask"; under "sigma_clip" the region is still computed but only as a diagnostic overlay (zero weight in the fit).

light.lens.refit.ps_sigma_clipfloat | null
null

Clip threshold in sigma for ps_treatment="sigma_clip"; null resolves to 4.0 whenever clipping is active. Ignored in the other modes.

light.lens.refit.ps_sigma_clip_itersint
3

Maximum sigma-clip reweight passes; stops early once the clipped-pixel set stops changing. Related fine-tuning: ps_sigma_clip_grow (int, default 1) binary-dilates the clipped set — a bare threshold clips the PSF core but leaves the wings just below it, and one ring of growth removes exactly the flux the Sersic would otherwise absorb; ps_sigma_clip_within ("all" | "arc" | "ps_aperture", default "all") confines where the clip may reject — an unrestricted clip also deletes lens-light pixels wherever the parametric profile fits badly (typically the galaxy core), which is the opposite of its purpose.

light.lens.refit.mask_arcbool
false

Zero-weight the arc region during the light-only fit. The refit target data − (source+PS) still carries arc flux when simple_source="stage1" (a smooth stage-1 source cannot reproduce arc detail), and that leftover is real signal the parametric light must not chase. Excluding it positionally removes it without the one-sided selection bias a residual clip introduces — membership is decided by geometry, not by how far the data sits above the current model.

arc_mask_inner_radius/arc_mask_outer_radius (float | null) build a REFIT-ONLY annulus (arcsec, centred on the point-source centroid) instead of reusing the CF arc mask — strongly recommended: the CF mask is sized for source reconstruction and is far too wide for a light fit; removing that whole band deletes exactly where the Sersic effective radius lives. A narrow annulus bracketing the ring removes the arc flux without that damage.

light.lens.refit.mask_pathstr | null
"data/mask_lens_only.fits"

Mask for the lens-light refit only. When data.cutout_size crops the modelling image, the refit deliberately runs on the full loaded frame so the galaxy's faint wings and sky remain constrained. This mask must therefore match the full frame—not the modelling cutout—and should exclude field galaxies while keeping the lens and sky active.

Unlike a full-frame data.likelihood_mask_path, this mask is not center-cropped. The same full-frame file can be assigned to both settings only when the desired pixel selection is genuinely identical.

related data.cutout_size data.likelihood_mask_path
light.lens.refit.sky_anchorfloat | null
null

If set (surface-brightness units of the image), the UNIFORM sky component is FIXED to this value during the refit — e.g. an externally calibrated sky level.

light.lens.refit.uncouple_ellipticitiesbool
true

Give each refit component (each Sersic and the MGE stack) its OWN ellipticity instead of one shared shape — allowing isophote twist and radial flattening gradients. A shared-ellipticity model of a real galaxy prints a characteristic quadrupolar residual; uncoupling removes it.

light.lens.refit.ellipticity_twist_sigmafloat
10.0

Gaussian prior width on the per-component ellipticity DELTAS (the twist amplitude); only used when uncouple_ellipticities is on.

light.lens.refit.uncouple_centersbool
true

Per-component centre deltas (lopsidedness) — the positional analogue of the ellipticity twist. center_shift_sigma (float, default 0.05) is the Gaussian prior width on the deltas. Two further stability switches share this block: freeze_foreground_perts (bool, default true) freezes foreground-plane perturbers at their warmstart values while the refit light is frozen in cf_joint — foreground masses deflect the grid the light is evaluated on, and letting them move drags the frozen galaxy render sub-pixel across the cusp, printing a core dipole.

light.lens.refit.smooth_boundsbool
false

Bound the Sersic index and ellipticities with BIJECTIONS (n = 0.5 + 7.5·sigmoid, e = 0.4·tanh) instead of a hard clip, and seed the Sersic indices distinctly (2.5/1/4) rather than all at 3.0. A hard clip has zero gradient outside its bounds, so a parameter Adam pushes past one is dead and can never return — a trap, not a constraint. Measured on real data the trap removal did not improve the fits (the data genuinely wants the n = 0.5 boundary), so the default is off; keep it available for diagnosing future parameter railing. distinct_n_init (bool | null, default follows this flag) splits the seeding choice out so bijection and init can be attributed separately.

light.lens.refit.n_sersic_minfloat
0.2

Sersic-index floor for the refit (n_sersic_max = 8.0 is the ceiling). The worked example uses 0.2, allowing a triple-Sersic refit to use a very shallow core component. There is little room below it: the Sersic normalisation approximation reaches zero at n ≈ 0.164, below which the profile degenerates to flat. Below ~0.35, treat the profile as a flexible fitting basis rather than a conventional Sersic component.

light.lens.couple_sersic_ellipticitiesbool
false

Couple the ellipticities of all Sersic lens-light components: L2/L3 share e1/e2 with L1. Removes four latents from a triple-Sersic model and prevents the components from twisting against each other — recommended when the extra Sersics are meant as radial-profile freedom, not isophote-twist freedom.

light.lens.mge.n_componentsint
20

Number of Gaussian components in the MGE stack, log-spaced in width between mge_sigma_min and mge_sigma_max. More components give smoother radial-profile freedom at the cost of one amplitude latent each.

related light.lens.refit.mge_n_components
light.lens.mge.sigma_minfloat (arcsec)
0.03

Width of the narrowest MGE Gaussian. Values well below the PSF width buy nothing — the convolution washes them out.

light.lens.mge.sigma_maxfloat (arcsec)
2.5

Width of the widest MGE Gaussian. In correction mode keep this small (a few tenths of an arcsec) so the stack stays a core correction; in full-MGE mode it must reach the lens-light envelope scale.

light.sky_backgroundbool
true

Add a uniform sky-background component to the lens light with a wide, data-driven prior on its amplitude (site sky_amp). Use when the cutout has an unsubtracted sky pedestal — otherwise that flux gets absorbed into profile wings and biases the lens-light (and thus source) decomposition.

light.point_sources.enabledbool
true

Whether the system contains multiply-imaged point sources (quasar images) to be modelled — the canonical time-delay-cosmography workflow. Set false for galaxy-galaxy strong lensing (extended source only). In that mode ALPACA skips point-source detection, the x_image/y_image/ps_amp latents, time-delay and ray-shooting likelihood factors, the entire PSF-reconstruction machinery (you must supply a fixed PSF), and point-source plot overlays.

With use_point_sources=false, config validation force-disables (with one grouped warning): psf.mode → "fixed", likelihood.use_time_delays, likelihood.use_rayshoot_consistency, likelihood.use_image_pos_offsets, likelihood.noise_model.noise_boost, and likelihood.noise_model.use_psf_error_map — all of these need image positions or point-source flux to be meaningful.
light.point_sources.fft_renderingbool
false

Experimental (anomaly-005 fix): render point sources by exact Fourier-shift placement instead of the bilinear gather. The bilinear gather broadens every point-source core by a constant tent of ~1/3 native pixel; FFT placement removes that systematic at the cost of wrap-around edge behaviour.

Experimental — validate against a bilinear run before adopting for production H₀ inference.

stages.gd

Stage 1 — multi-start gradient descent on the smooth model (MAP phase 1).

stages.gd.source.typestr
"shapelets" allowed"shapelets", "sersic", "corr_field"

Source representation used during the stage-1 multi-start gradient descent. "shapelets" (Sersic + shapelet basis, size n_max) is the production default — smooth, analytic and fast to optimise from random starts. "sersic" drops the shapelets. "corr_field" runs GD directly on a pixelated correlated-field source (no staged flow; expensive and non-convex — the staged shapelets → CF path exists precisely because this is hard).

stages.gd.source.n_maxint
16

Maximum Shapelet order. The number of basis functions grows as (n_max+1)(n_max+2)/2 — n_max=16 gives 153 components. Higher orders resolve finer source structure but add latents and can start fitting noise or absorbing PSF residuals. Unused unless source_type="shapelets" or the staged CF flow (whose stage 1 is a Shapelets fit).

stages.gd.optimizer.startsint
10

Number of Phase-1 random starts. The worked example uses 10 together with the annealing ladder, which removes much of the multistart lottery. Flat multistart runs generally benefit from at least 50; use 100–200 for production runs on lenses with strong degeneracies.

stages.gd.optimizer.adam.stepsint
1000

Adam steps per start in Phase 1 (exploration). Enough to reach the basin, not to polish — L-BFGS follows.

stages.gd.optimizer.adam.lrfloat
0.003

Adam learning rate, shared by both phases (modulated by warmup and cosine decay). Too high loses fragile latents (PSF background, CF spectrum); too low stalls exploration.

stages.gd.optimizer.adam.warmup_fractionfloat
0.1

sampling

Posterior backend selection and PSF marginalisation.

sampling.samplerstr
"nifty" allowed"nuts", "nautilus", "nifty", "default"

Posterior sampling backend:

  • "nuts" — classical NumPyro NUTS on the physical parameters. Right for Shapelets/Sersic models with moderate dimensionality.
  • "nautilus" — nested sampling. Practical up to ~50 parameters and the only backend that returns a log-evidence (model comparison).
  • "nifty" — NIFTy-based inference (geoVI and/or NUTS in ξ-space). Required for correlated-field sources; also the backend that supports PSF marginalisation.
  • "default" — auto-select: NIFTy for correlated fields, Nautilus for ≤ 50 parameters, NUTS otherwise.
Nautilus does not scale past ~50 parameters — with image-position offsets, perturbers and a large Shapelet basis you can exceed that quickly; check the printed parameter count.
sampling.nifty.modestr
"nuts_only" allowed"vi+nuts", "vi_only", "nuts_only"

NIFTy sub-mode, consulted only when the effective sampler is "nifty":

  • "vi+nuts" — geoVI first, then NUTS-in-ξ refinement warm-started from it. Asymptotically exact, and enables the VI-derived mass matrices.
  • "vi_only" — geoVI only. Fast, but a Gaussian (in ξ) approximation.
  • "nuts_only" — NUTS-in-ξ warm-started from the gradient-descent MAP, skipping VI entirely.
sampling.n_posterior_samples_finalint | null

Target posterior sample count after final subsampling — the size of the chains written to posterior_samples.npz and used by corner plots and downstream cosmography.

sampling.marginalize_psfbool
false

Keep the PSF Moffat-core parameters as free latents during posterior sampling, so the posterior marginalises over PSF uncertainty instead of freezing the kernel at the final GD value. The background grid stays frozen at its GD value (a ~450² grid is intractable as VI latents and is pinned by the error-map floor). Default false reproduces legacy frozen-kernel sampling exactly.

sampling.marginalize_psf_backgroundbool
false

When marginalize_psf is on, also marginalise the PSF background — but only the high-res pixels inside a central box of side ≈ fwhm_box × fwhm × upsampling, where the PSF actually carries signal, sampled as a perturbation around the GD-recovered grid. Keeps the sampled-background latent count tiny (= side²) so geoVI/NUTS stays tractable; the kernel-space prior anchors it to the measured error map.

Meaningless without sampling.marginalize_psf=true.
sampling.marginalize_psf_background_fwhm_boxfloat
80.0

Size of the marginalised background box, in units of the PSF FWHM (times the upsampling factor), giving a box of side fwhm_box × fwhm × upsampling centred on the kernel. Only pixels inside the box become free latents. The side is clipped to the full high-res grid, so once fwhm_box × fwhm × upsampling reaches image_size_up, the box covers every background pixel. The example value of 80.0 therefore resolves to the full high-resolution grid if background marginalisation is enabled; in the worked run it is dormant because marginalize_psf is false.
