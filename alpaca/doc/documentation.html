GuideOverview

ALPACA fits a strong-lens model to an image: a mass model for the deflector (EPL + external shear, optionally multipoles, a broken power law and line-of-sight perturbers), parametric lens light, a source (shapelets, then a pixelated correlated field), a PSF that is refined together with the lens, and, for lensed quasars, the point images and their time delays. It runs in JAX, so every stage is differentiable and runs on a CPU, an NVIDIA GPU or an Apple GPU.

A run has two phases:

  1. MAP: a staged gradient descent finds the best-fit model (§ The staged pipeline).
  2. Posterior: sampling around it (NIFTy NUTS / geoVI, NumPyro NUTS or Nautilus). For cosmography the time delays turn the model into a time-delay distance and H0, blinded by default.

The methods and their validation are in the paper: Krizic et al. 2026, arXiv:2609.04312.

GuideThe staged pipeline

With the default joint PSF (psf.mode: "joint") the MAP is found in stages, each starting from the previous one. This is the recommended path for every lens.

stagewhat is fittedwhymain knobs
1 · shapelets
03_multistart/stage1_shapelets		 Mass, lens light (e.g. double Sérsic), a shapelet source, the live PSF; many random starts, annealed (noise inflated ×16 → ×1) and culled by successive halving, then the best are refined. A smooth source makes the multistart robust: it finds the right mass basin (and, for galaxy–galaxy lenses, the lensed instead of the unlensed solution). anneal, halving, refine, n_max
2 · lens-light refit
stage2_lens_light_refit		 The lens light alone (e.g. triple Sérsic) on the full frame, after subtracting the stage-1 source and point sources. The full frame constrains the light profile's wings and the sky, which the small cutout cannot. refit.profile, refit.mask_path, simple_source
3 · CorrField joint
stage3_cf_joint		 Phase A grows a pixelated correlated-field source with everything else pinned; phase B fits source, mass, light and PSF together. The pixelated source captures the real source structure the shapelets miss; this is the model you judge and sample. loglogavgslope, num_pixels, arc mask, adam_steps
PSF-error b (quasars) After GD, the amplitude b of σ²eff = σ² + b²·PS² is fitted; it stays free in sampling (post_gd_free). Down-weights the quasar cores, where any PSF error dominates χ². use_psf_error_map, psf_error_b_max
warm start → sampling
04_sampling, 05_posterior		 The MAP is mapped exactly into the sampler's latent space, then NUTS (and optionally geoVI) samples. Uncertainties, the time-delay distance, H0. nifty.mode, target_accept

Use a shapelet-only model (psf.mode: "fixed") only when you specifically want one, for example as a quick systematic check.

GuideJudging a model

Look at pictures before numbers. A model is acceptable when:

  • the normalised residuals have no coherent structure: no arcs (source or mass), no rings or dipoles at quasar cores (PSF or astrometry), no quadrupole at the centre (lens light), no gradient (sky);
  • χ² is balanced by region: quasar cores, arcs, centre and outskirts. A global χ²red hides compensation, for example a component that fits the noise in one place (χ² well below the empty-sky level) while another region is not fitted at all. A block-binned χ² map shows this at a glance;
  • nothing sits at a prior bound (boundary_flags.txt; check the GD endpoint too);
  • the model is physical: γ about 1.8–2.3, mass and light aligned within about 10–20°, perturber masses consistent with their light, a galaxy-like source that does not touch the source-grid edge;
  • a different random seed lands in the same solution, and an extended model fits at least as well as the baseline it contains;
  • for galaxy–galaxy lenses: it is lensing, not painting. θE is not at its lower bound, the mass is centred on the light, the critical curve runs through the arcs, and the source is smaller than the arcs.

Drizzled data have correlated noise: a good fit can sit at χ²red ≈ 0.5. Judge structure and differences between models, not the distance from 1.

GuideBlinding

For cosmography, keep one campaign key in ALPACA_BLINDING_KEY (never in a config or a log). Blinded quantities (DΔt, H0, γ …) are stored as offsets from the posterior mean, so runs are compared through differences only. python -m alpaca.unblind <run> unblinds once the collaboration decides. GD files (best_fit_params_full.npz) hold true values; treat run directories as internal.

Configuration referenceHow the config works

A run is configured by one JSON file (config.json). Every run copies the configuration it used into <run>/config/config.json, so any run can be reproduced or modified. Data paths, image positions and time delays live in run_alpaca.py (see above); everything else is here. Options you leave out take the default shown below. The shipped config.json is a complete production configuration (HE0435−1223); where its value differs from the code default, both are shown.

All 268 options of ALPACA 0.4.2, generated from the code. Tags: essential (33): you set or check these for every lens; common (39): budgets and the usual model variants; advanced (196): expert knobs, safe at their defaults.

Data · data · 8 knobs

Pixel scale, the model cutout and the likelihood mask. The image, noise map and PSF files themselves are set at the top of run_alpaca.py.

data.cutout_sizeint | Nonenullconfig.json: 219essential

If set (and smaller than the loaded image), the pipeline center-crops the loaded image and noise map to this many pixels per side for every normal modelling stage and sampling. A full-frame data.likelihood_mask_path is center-cropped with the same offset; an already cutout-sized likelihood mask is accepted unchanged.

The full loaded frame is retained for the lens-light refit, which fits the parametric light on the larger frame for better outer-profile and sky constraints. Its cutout-invariant parameters transfer back to the cropped model unchanged, and its separate mask must match the full frame.

Mass model · mass · 34 knobs

The main deflector (EPL+shear, multipoles, broken power law), the θE prior for galaxy–galaxy lenses, and line-of-sight perturbers.

mass.main.multipoles.orderslist[int][]essential

Angular multipole orders added to the main deflector, e.g. [3, 4]. Each order m adds the convergence κ_m = a_m·cos[m(φ−φ_m)]/(2r) and TWO sampled sites, the Cartesian pair lens_a{m}_cos/lens_a{m}_sin (single-valued and smooth through zero — the polar (a_m, φ_m) pair is 2m-fold multimodal and singular exactly at the a_m=0 null-test point). All amplitudes zero = the EPL, bit-for-bit.

m=4 is boxy/discy — the mode with real photometric backing (a₄/a ~ 1–2% in ellipticals). m=3 is the triangular mode. m=1 is supported (it needs a special r·ln r potential — the scale-free form divides by zero) but see the warning.

related: mass.main.profile
runtime: MultipoleConfig.orders
mass.main.profilestr"EPL+Shear"essential

Radial mass profile of the main deflector.

  • "EPL+Shear" — elliptical power law + external shear, one slope lens_gamma. The historical model (legacy alias "epl").
  • "BPL+Shear" — elliptical broken power law + external shear (legacy alias "bpl"): slope gamma_in inside a break radius, gamma_out outside. Samples lens_gamma_in, lens_gamma_out, lens_r_break_frac and removes lens_gamma. Reduces to the EPL exactly at gamma_in = gamma_out (verified to ~1e-13), and θE keeps its EPL meaning (mean convergence 1 inside θE) so the two models are directly comparable.

The BPL has no closed-form deflection — it is evaluated by desingularised Gauss-Legendre quadrature (Keeton 2001), costing ~×1.8 per gradient.

The profile string selects the RADIAL model only — angular structure is added independently via mass.main.multipoles.orders (combinable with either profile), and the external shear is always part of the model.
